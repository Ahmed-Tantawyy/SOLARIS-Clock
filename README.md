# SOLARIS-Clock
A Clock that has 4 modes, which are ( alarm, stopwatch, timer, and normal watch). It has 4 switches to control it, one buzzer for the sound, and a display that shows the time.

The BOM:
1.  1x Seeed XIAO ESP32C3.
2.  4x MX-Style Keyboard Switches.
3.  4x White Blank DSA Keycaps.
4.  1x 2.25in TFT Screen.
5.  1x 3.3V Piezo Buzzer.
6.  1x 2.54mm 8 Pin Male Header (For connecting the screen).
7.  8x 20cm Female-Female Jumper Wires (For connecting the screen off of the pcb).
8.  8x M3x5x4 Heatset Inserts.
9.  4x M3x8mm Screws.
10.  4x M3x16mm Screws.
